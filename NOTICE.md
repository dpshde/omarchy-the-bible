https://bereanbible.com/bsb_usj.zip

## route.bible

The plugin is named The Bible. Opening a selection uses canonical
route.bible URLs; this plugin is not a replacement for the website.

## margin.bible

Outline opens `https://margin.bible/{slug}` on the same grab-bcv / OSIS
address as route.bible. Notes live in margin.bible; this plugin only
launches the reader.
